# 0.1.1 public preview

Echo presents music metadata in adaptive Plaque, Sleeve and Showcase faces, with a floating surface, optional earthy frame, intact artwork, honest playback progress and restrained text transitions. Glow can reuse an existing OnSpotify palette or use a chosen color; paused glow stays steady and stale artwork/glow fade away.

Reuse an enabled MMM-OnSpotify 7.0.2 connection, supply compatible playback notifications, or configure an independent Spotify application with a protected credential file. The companion is optional. Echo displays playback and does not play, capture or analyze audio.

Includes explicit missing, paused, stale, authorization and rate-limit states, bounded metadata and approved service/image URLs, reduced-motion support and lifecycle cleanup. Focused HTTP checks use controlled responses; the owner's Raspberry Pi trial verified playback through the existing OnSpotify connection. Independent direct Spotify authorization has not been verified with a live account. Public screenshots use fictional metadata and project-owned artwork. See README, VALIDATION.md and THIRD_PARTY_NOTICES.md for setup, account requirements and verification limits.
